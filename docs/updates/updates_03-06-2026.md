## Contexte technique utile

- Les tags bruts sont dans `place.tags` (objet JSON) — toujours disponible côté frontend
- `healthcare:speciality` peut contenir plusieurs valeurs séparées par `;` (ex: `cardiology;pediatrics`) → à splitter
- `health_facility:MG` contient des codes officiels malgaches : `CSB I`, `CSB II`, `CHD I`, `CHD II`, `CHU`, `CHRR`, etc.
- `operator:type` contient : `public`, `private`, `ngo`, `religious`, `community`
- Leaflet nécessite un fix spécifique avec Vite pour les icônes par défaut (import de `leaflet/dist/images/marker-icon.png` etc.)
